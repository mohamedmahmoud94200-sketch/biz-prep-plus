# معاينة وتصدير مطابقان لكل بروفورما

## ما سيتم بناؤه
- تحويل مساحة البروفورما داخل المتصفح إلى صفحات A4 أفقية واضحة، مع حدود الصفحة وفواصل الصفحات قبل التصدير.
- إضافة تحكم شبيه بـ Excel:
  - سحب حد كل عمود لتغيير عرضه مباشرة من الجدول.
  - تغيير ارتفاع كل صف.
  - تحديد خلية واحدة وتغيير حجم خطها أو جعلها Bold.
  - إعداد حجم خط وBold لعمود كامل، مع أولوية إعداد الخلية عند تخصيصها.
- ضبط الصور تلقائيًا داخل مساحة الخلية دون قص أو تمديد، مع بقاء أداة التكبير والتحريك الحالية اختيارية.
- حذف عمود Actions من المعاينة المخصصة للعميل ومن PDF وPowerPoint، مع إبقائه ظاهرًا للمستخدم أثناء التعديل فقط.

## الحفظ لكل بروفورما
- تخزين عرض الأعمدة، ارتفاع الصفوف، تنسيق الأعمدة، وتنسيق الخلايا داخل بيانات البروفورما نفسها.
- زر Save Now يحفظ تصميم البروفورما النشطة فقط؛ الانتقال إلى بروفورما أخرى يعرض تنسيقها المستقل.
- البروفورما الجديدة تبدأ بتنسيق افتراضي واضح بدل نسخ تغييرات بروفورما أخرى دون قصد.

## التصدير المطابق
- استخدام نفس مقاسات صفحة A4 الأفقية ونفس توزيع الأعمدة والصفوف والخطوط والصور في المعاينة وPDF.
- إنشاء PowerPoint من لقطات الصفحات نفسها بدل إعادة رسم الجدول، لتكون الشرائح مطابقة بصريًا للمعاينة دون ترحيل النص أو الصور.
- كل صفحة معاينة تقابل صفحة PDF وشريحة PowerPoint واحدة.

## تفاصيل فنية
- توسيع بيانات التنسيق المخزنة داخل `meta` دون إنشاء حسابات أو صلاحيات جديدة.
- تقسيم المنتجات إلى صفحات حسب ارتفاعات الصفوف الفعلية مع تكرار رأس الجدول في كل صفحة.
- منع تجاوز النص والصور لحدود الخلايا، مع التفاف النص تلقائيًا.
- التحقق من المعاينة على المقاس الحالي وعلى شاشة مكتبية، ثم فحص ملفات PDF وPowerPoint الناتجة بصريًا.
